# 모자(MOJA) 요구사항 정리 (2026-08-25 기준)

이번 세션에서 사용자가 요청한 것 전부를 시간 순으로 정리했습니다. "했던 것"은 실제로 배포까지
끝난 것, "수정해야 할 것"은 요청했지만 알려진 문제/한계가 남아있는 것, "더 개발하면 좋을 것"은
아직 손 안 댄 백로그입니다.

## 2. 수정해야 할 것 (요청은 반영됐지만 알려진 한계·미해결 문제)

| 문제 | 설명 | 관련 요청 |
|---|---|---|
| **매칭결과 탭이 여전히 DB 컬럼을 안 씀** | "전체 공고 보기/지역별/현재상태별/관심분야로" 4개 탭은 DB의 `classify.ts` 분류 컬럼을 쓰는데, 정작 자격 **판정**(매칭결과 탭, `realMatch.ts`)은 여전히 매 요청마다 원문 텍스트를 정규식으로 재검사함. 검수자가 DB 컬럼을 고쳐도 실제 판정엔 반영 안 됨 | #1 |
| **`announcements_all` 뷰의 RLS 우회** | anon 키로 이 뷰를 직접 조회하면 `pending`(미승인) 공고까지 노출됨 (개별 테이블은 정상 차단). `alter view announcements_all set (security_invoker = on);` 필요 | (검수 가이드 작성 중 발견) |
| **현재상태별 필터의 데이터 한계** | DB엔 "재학 요건 있음/없음" 이진 플래그만 있어서, 취업/미취업/기타를 선택해도 결과가 똑같음. 재학 여부만 실질적으로 구분됨 | #19 |
| **`youthCenter` 소스 거주지 필터 미작동** | 지역코드(zipCd)→지역명 변환 로직이 없어서 이 소스만 거주지 필터가 안 걸림 | (기존부터 알려진 문제) |
| **`protectionEndTypesApplicable` placeholder** | 항상 5종 보호종료유형 전부를 반환 — 본문에서 배제 신호를 찾는 로직 없음 | (기존부터 알려진 문제) |
| **검수 UI 없음** | 신규 동기화 공고는 자동 승인되고, 잘못된 걸 걸러내려면 Supabase SQL Editor에서 수동으로 해야 함 | (검수 가이드로 문서화만 됨) |
| **`CRON_SECRET` 미설정** | 크론 라우트(`/api/sync-announcements`)가 보호 없이 열려있음. 코드는 이미 대응해뒀는데 환경변수만 안 넣은 상태 | #18 |
| **`description_tags` 키워드 사전이 임의 큐레이션** | 24개 키워드로 시작한 거라, 다른 중요한 단어가 빠져있을 수 있음 | #23 |
| **main과 dev 코드 격차** | 사용자가 의도적으로 그대로 두기로 함 — 나중에 "웹사이트에 나온 기능이 main엔 없다"고 헷갈릴 수 있으니 유의 | #27 |

## 3. 더 개발하면 좋을 것 (아직 손 안 댄 것)

| 항목 | 설명 | 관련 요청/맥락 |
|---|---|---|
| **로드맵/지속 알림 기능** | 세션 초반에 "가입 시 정보 기반으로 지속적인 알람이나 로드맵 형식이 필요하다"고 요청했었는데, **실제로 구현 안 됨**. 개인화 요약 카드까지는 만들었지만, 이메일/푸시 알림이나 "다음 단계 로드맵" UI는 아직 없음 | 세션 초반 개인화 요청의 일부 — 놓치지 말 것 |
| **멘토-멘티 커뮤니티** | 자립을 마친 사람=멘토, 현재 자립준비청년=멘토 매칭. 신원인증이 먼저 되어야 의미 있어서 보류 중 | 세션 초반 요청 |
| **신원인증 설계** | "진짜 자립준비청년인지" 확인하는 수단. 지금 카카오 로그인은 계정 식별용일 뿐 자격 검증이 아님. 멘토-멘티 등 후속 기능의 전제조건 | 여러 차례 논의됨 |
| **`realMatch.ts`를 DB 컬럼 기반으로 전환** | 위 "수정해야 할 것" 1번의 근본 해결책. 검수 워크플로우가 실제로 의미를 가지려면 필수 | #1 |
| **커뮤니티 악용 방지(도배·신고)** | MVP 범위 밖으로 명시적으로 뺀 상태 | (구 핸드오프 문서부터 계속 보류) |
| **GitHub Collaborator 초대** | 저장소는 만들었지만 팀원을 아직 초대 안 함 | #2 |
| **성별 항목** | 온보딩엔 안 넣기로 함(사용자 결정). 커뮤니티 글쓰기 화면에만 로컬 저장으로 남아있음 | (별도 논의에서 "그냥 넘어가자"로 결론) |
